# POZzlePiece Platform
**AUTHOR . . . . . . .** Shahar Ankonina                                                                                
**DESCRIPTION. . .** A modern dating platform and safe community web application built for the HIV+ community using vanilla HTML, CSS, and JavaScript.

---
## About
This repository contains the source code for **POZzlePiece**, a curated safe space and dating platform designed exclusively for people who are HIV+. Built entirely with vanilla HTML, CSS, and JavaScript, the interface features a custom brand color palette, smooth multi-page layouts, and responsive design.

The platform includes an interactive Community Q&A board, a structured Careers hub linked directly to LinkedIn, direct CEO contact routing pre-addressed to `perfect.fit@pozzlepiece.com`, and an early-access beta tester signup experience—all engineered without heavy external frameworks to ensure performance and discretion.

---
## Features
- *About & Vision:* Clean storytelling introducing the mission and safe-space mechanics.
- *Community Q&A Board:* Interactive question submission, filtering by topic, and upvoting mechanics.
- *Careers Hub:* Filterable job board with quick-apply drawers and direct links to the official LinkedIn company page.
- *Direct Contact Flow:* Streamlined executive contact interface with one-click email copying pre-addressed to `perfect.fit@pozzlepiece.com`.
- *Beta Access Flow:* Modal-driven waitlist registration for early adopters.
- *Zero-Dependency Stack:* Engineered 100% with native web standards—no React, Tailwind, or bundled runtime dependencies.

## Usage
- This is a static multi-page web application requiring no complex build steps or package installations.
- Clone the repository and open `index.html` in any modern web browser or host via static deployment platforms.
- Alternatively, launch a local server (e.g., VS Code Live Server) to preview changes in real time.

### Build & Run
1. Clone the repository:
```bash
git clone [https://github.com/AnkoninaShahar/AnkoninaShahar.github.io.git](https://github.com/AnkoninaShahar/AnkoninaShahar.github.io.git)
cd AnkoninaShahar.github.io
```

2. Open in browser (macOS/Linux/Windows):
```bash
# macOS
open index.html

# Windows (CMD)
start index.html
```
